# Assignment 05: Chicago Homicide Analysis

## Project Overview

My project uses R and Quarto to analyze the geographic
distribution of homicides in Chicago.

The analysis includes maps of homicide locations, homicide
counts, and arrest rates by census tract. It also examines
homicides near CTA train stations and uses Census ACS data
to create maps of demographic and economic characteristics.

## Project Files

- `index.qmd`: R code, analysis, and maps.
- `index.html`: Final HTML report generated by Quarto.
- `assignment05.Rproj`: RStudio project file.
- `README.md`: Project description and instructions.
- `.gitignore`: Files excluded from GitHub.
- `images/`: Maps generated using the custom R function and purrr.
- `data/`: Local data files used in the analysis (not uploaded to GitHub).

## Data Sources

This project uses three main data sources:

1. Chicago crime data (`crimes-reduced.csv`) provided on Canvas.
2. Chicago 2010 Census Tract boundaries and CTA rail station
   locations from the Chicago Data Portal.
3. American Community Survey (ACS) data from the US Census Bureau.

The crime data and shapefiles are not included in this repository.

## How to Reproduce the Analysis

1. Download `crimes-reduced.csv` from Canvas.
2. Create a `data` folder in the project directory and place
   the CSV file inside it.
3. Download the Chicago Census Tract and CTA station shapefiles
   from the Chicago Data Portal. Unzip the files and place them
   in the `data` folder. Keep the related shapefile components
   together.
4. Open `assignment05.Rproj` in RStudio.
5. Install the required R packages:

   ```r
   install.packages(c(
     "tidyverse", "lubridate", "sf", "patchwork",
     "tidycensus", "httr", "jsonlite", "testthat",
     "purrr"
   ))
   ```

6. Obtain a Census API Key from the US Census Bureau.
   Save the key in RStudio using:

   ```r
   tidycensus::census_api_key("YOUR_API_KEY", install = TRUE)
   ```

   Restart R after saving the key.

7. Open `index.qmd` and click Render to generate `index.html`.

The analysis also saves additional maps in the `images` folder.

## Notes

The analysis uses a rolling ten-year window based on the
current date, subject to the years available in the crime dataset.

The `data` folder and Census API credentials are excluded
from GitHub through `.gitignore`.
